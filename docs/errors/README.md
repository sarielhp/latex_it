# LaTeX & TeX Error Reference Catalog

This catalog documents common LaTeX and TeX compilation errors, their root causes, canonical reference links, and how [`latex_it`](../../latex_it) identifies and diagnoses each issue.

---

## 1. Classification & Architecture

Errors during compilation originate in one of three layers:

1. **TeX Engine Primitives**: Generated by the TeX core parser (`pdftex`, `xetex`, `luatex`). In `-file-line-error` mode, these appear as `<file>:<line>: <message>.`.
2. **LaTeX2e Kernel Errors**: Emitted via `\@latex@error` (e.g. environment mismatches, missing items). These appear as `<file>:<line>: LaTeX Error: <message>.`.
3. **Package-Specific Errors**: Emitted via `\PackageError{<pkg>}{...}` (e.g. `amsmath`, `hyperref`, `biblatex`, `tikz`).

---

## 2. `latex_it` Diagnostic Tiers

| Handling Level | Description |
| :--- | :--- |
| **`Pre-Flight`** | Detected statically *before* compilation via [`LaTeXBraceChecker`](../../lib/latex_it/brace_checker.rb) (e.g. unclosed braces, inverted labels, and environment mismatches). |
| **`Direct`** | Captured by [`error_line_match`](../../lib/latex_it/diagnostics.rb), isolated to file and line, highlighted with modern separator headers, and formatted for AUCTeX buffer jumps. |
| **`Standard`** | Captured via generic `-file-line-error` logging with source snippet and line attribution. |
| **`Fatal`** | Critical engine termination (`Emergency stop`); surfaces the primary fault line and points to the raw transcript. |

## 4. On-Demand Error Corpus Testing

The reproducer cases in this directory provide verification fixtures. Each subdirectory contains:
- `example.tex`: Minimal self-contained document triggering the error.
- `README.md`: Explanation of why the error occurs, the raw log signature, and how to resolve it.

### Running Corpus Verification
To keep continuous integration and quality gates fast, the error corpus is executed **on demand** and completely decoupled from `tools/gate`:

```bash
# Run standalone verification across all error corpus reproducers
rtk ./tools/test_error_corpus
```
